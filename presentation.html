Responsive Design

Mobile-First Responsive CSS

Base styles target mobile (≤519px). Four progressive min-width breakpoints enhance the layout. The bottom nav shows on mobile and hides on desktop — and vice versa for the top nav.

/* BASE: Mobile (≤519px) */
.nav-links { display: none; }
.bottom-nav { display: flex; }
.kpi-strip { grid-template-columns: repeat(2,1fr); }
.main-grid { grid-template-columns: 1fr; }

/* Small mobile (≥520px) */
@media (min-width: 520px) {
  .hero-heading { font-size: 32px; }
}

/* Tablet (≥720px) */
@media (min-width: 720px) {
  .hero {
    grid-template-columns: 1fr auto;
    padding: 36px 40px;
  }
  .hero-heading { font-size: 36px; }
}

/* Large tablet (≥940px) */
@media (min-width: 940px) {
  .kpi-strip { grid-template-columns: repeat(4,1fr); }
  .main-grid { grid-template-columns: 1fr 330px; }
}

/* Desktop (≥1080px) */
@media (min-width: 1080px) {
  .nav-links { display: flex; }
  .bottom-nav { display: none; }
  .main-grid { grid-template-columns: 1fr 370px; }
  .hero-heading { font-size: 42px; }
}

Dual Navigation Strategy

SpendSmart uses a responsive dual-nav strategy: a sticky glassmorphism top bar for desktop and a fixed bottom tab bar for mobile — switching at the 1080px breakpoint.

🖥 Desktop
Top Navigation
Sticky, backdrop-filter blur(24px), pill-style active links, notification badge, user avatar chip with online dot.
📱 Mobile
Bottom Tab Bar
Fixed bottom, 5 items with icons + labels, prominent indigo FAB ➕ in the centre with glow box-shadow.
✨ Both
Glassmorphism
rgba(5,7,13,0.8) + backdrop-filter: blur(24px) saturate(180%) for the frosted glass look.

Animations & Motion

8 Purposeful CSS Animations

Every element animates with intent — from page-load stagger sequences to hover lift. All implemented with pure CSS keyframes and transitions, zero JS animation libraries.

/* Stagger slide-up on page load */
.slide-up {
  animation: slideUp 0.6s cubic-bezier(.4,0,.2,1) both;
}
.delay-1 { animation-delay: 0.07s; }
.delay-2 { animation-delay: 0.14s; }

@keyframes slideUp {
  from { opacity:0; transform:translateY(24px); }
}

/* Card hover lift */
.card:hover {
  transform: translateY(-2px);
  box-shadow: 0 10px 36px rgba(0,0,0,.3);
}

/* Gradient name shimmer */
.hero-name-gradient {
  background-size: 200% 200%;
  animation: gradientShift 4s ease infinite;
}
@keyframes gradientShift {
  0% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
}
✓
slideUp — hero, KPI cards, and sections appear with opacity + Y-translate stagger (0.07s delay increments)
✓
dialFill — SVG arc stroke-dashoffset animates from 515.22 → 144.26 over 1.8s
✓
barGrow — chart bars scale from scaleY(0) using transform-origin: bottom
✓
fillBar — goal/KPI progress bars animate width 0% → target via cubic-bezier easing
✓
wave — 👋 emoji oscillates between 20° and −8° rotation on infinite loop with 1s delay
✓
pulse — notification badge and eyebrow dot breathe with scale(1.15) loop every 2s
✓
gradientShift — hero name gradient background-position shifts, creating a shimmering colour flow
✓
floatBlob — three mesh orbs drift in sinusoidal paths (30px, 40px ranges) every 22–30s
